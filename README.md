# Database-SHAWQ5k
This repository contains the archaeomagnetic and volcanic database used for the  development of the SHAWQ5k  global archaeomagnetic reconstruction( Puente-Borque et al., in prep) updated and reviewed as March 2026..

Data are organised by columns as:

[Year, Temporal uncertainty, Latitude (°), Longitude (°), Declination (°), Inclination (°), α95 (°), Intensity (μT), Intensity uncertainty (μT), Directional quality weight (WqD), Intensity quality weight (WqF), Spatial weight (Wk), Code ID]

Each row corresponds to a single archaeomagnetic or volcanic record. NaN values indicate that the corresponding directional or intensity information is not available for that record.

This file is filtered to eliminate outliers and data with too high uncertanities.
